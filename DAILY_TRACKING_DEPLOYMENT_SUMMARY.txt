AUTOMATION SETUP
================================================================================

GitHub Secrets Required (8 total):
1. GUMROAD_API_KEY              → Gumroad developer API
2. STRIPE_SECRET_KEY            → Stripe payment tracking
3. YOUTUBE_API_KEY              → YouTube Analytics API
4. EMAIL_PLATFORM_API_KEY       → Mailchimp/ConvertKit/Klaviyo
5. AFFILIATE_API_KEY            → ShareASale/CJ/Impact/etc.
6. TRADING_API_KEY              → Robinhood/Tradier/etc.
7. SENDGRID_API_KEY             → Email delivery
8. SLACK_WEBHOOK_REVENUE_ALERTS → Slack notifications

Automation Schedule:
- Hourly: Gumroad dashboard check (top of every hour)
- Daily: 9 AM UTC full consolidation
- Daily: Email summary (post-consolidation)
- Daily: Slack notification (post-consolidation)
- Daily: Git auto-commit of reports

QUICK START (10 MINUTES)
================================================================================

Step 1: Copy Template (2 min)
  cp DAILY_REVENUE_TRACKING_TEMPLATE.md tracking/daily_tracking_$(date +%Y-%m-%d).md

Step 2: Fill Baseline Data (5 min)
  - Gumroad product names
  - Email list size
  - Social media follower counts
  - Affiliate program names
  - YouTube channel info
  - Trading account details

Step 3: Add GitHub Secrets (3 min)
  GitHub → Settings → Secrets → Actions
  Add 8 secrets from list above

Step 4: Enable Workflow (automation takes over)
  .github/workflows/daily_revenue_tracking.yml enabled

Total Setup Time: ~10 minutes
First Report: 9 AM UTC (automated)
