                          ENVIRONMENT VARIABLES

Required:

RUNTIME_API_URL
  Description: Base URL of the runtime backend API
  Example: https://runtime.alreadyhere.com
  Default: http://runtime:8080
  Required: YES

CLIENT_API_KEY
  Description: API key for authenticating with runtime backend
  Example: <your-production-key-here>
  Default: default-dev-key (dev only)
  Required: YES

Optional:

CLIENTS_DB_PATH
  Description: Path to clients.db on runtime filesystem
  Example: /home/opc/profitengine/clients.db
  Default: clients.db (relative to runtime cwd)
  Required: NO

                            METRICS REFERENCE

SUMMARY CARDS (Real-Time KPIs)
──────────────────────────────

1. Active Traders Today
   Source: /api/clients/stats → active_traders field
   Value: Integer count
   Meaning: How many traders traded today
   Color: Cyan (primary)

2. Total Trades Today
   Source: /api/clients/stats → total_trades field
   Value: Integer count
   Meaning: Total trade volume for the day
   Color: Cyan (primary)

3. Daily P&L Total
   Source: /api/clients/stats → total_pnl field
   Value: Float USD amount
   Color: Green (positive) or Red (negative)
   Meaning: Total platform profitability

4. Avg P&L per Trade
   Calculated: total_pnl / total_trades
   Value: Float USD amount
   Color: Green (positive) or Red (negative)
   Meaning: Average profitability per trade

LEADERBOARDS (Rankings)
───────────────────────

1. Top 5 Performers (Win Rate)
   Metric: Percentage of winning trades
   Secondary: Total P&L
   Window: Last 30 days (configurable)
   Use Case: Showcase trading excellence

2. Top 5 Biggest Gainers (P&L %)
   Metric: Percentage gain on capital
   Secondary: Total P&L
   Window: Last 30 days (configurable)
   Use Case: Marketing testimonials

3. Upsell Candidates
   Criteria: score > 0.5 on (PnL + Win Rate + Trades + Activity)
   Tiers: Free or Standard only
   Minimum: 10 trades required
   Urgency: High (>0.75), Medium (0.5-0.75), Low (<0.5)
   Use Case: Sales team targeting
