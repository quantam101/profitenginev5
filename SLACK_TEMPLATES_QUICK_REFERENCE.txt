================================================================================
  GITHUB ACTIONS AUTOMATION
================================================================================

Create: .github/workflows/daily-slack-updates.yml

Example Schedule:
  8 AM UTC:  0 8 * * *           (every day)
  6 PM UTC:  0 18 * * *          (every day)
  10 AM UTC: 0 10 * * 0          (every Sunday)
  12 AM UTC: 0 0 1 * *           (1st of every month)

Minimal Workflow:
  name: Daily Slack Updates
  on:
    schedule:
      - cron: '0 8 * * *'        # 8 AM
      - cron: '0 18 * * *'       # 6 PM
      - cron: '0 10 * * 0'       # Sunday
      - cron: '0 0 1 * *'        # 1st of month

  jobs:
    update:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-python@v4
          with:
            python-version: '3.11'
        - run: pip install aiohttp
        - run: python pipeline/slack_integration_example.py all
          env:
            SLACK_BOT_TOKEN: ${{ secrets.SLACK_BOT_TOKEN }}
            SLACK_REVENUE_CHANNEL: C0B8VN2S89Y

================================================================================
  STATUS INDICATOR THRESHOLDS
================================================================================

Achievement % Calculation:
  • Actual vs Target: (actual / target) × 100

Status Assignment:
  ON_TRACK:  >= 100%
  BEHIND:    85-99%
  ALERT:     70-84%
  CRITICAL:  < 70%

Emoji Mapping:
  ON_TRACK:  🟢 (green_circle)
  BEHIND:    🟡 (yellow_circle)
  ALERT:     🟠 (orange_circle)
  CRITICAL:  🔴 (red_circle)

================================================================================
  COMMON METRICS CALCULATIONS
================================================================================

Click-to-Open Rate %:
  (clicks / opens) × 100

Daily Average (weekly report):
  week_revenue / 7

Average Deal Size (monthly):
  total_revenue / deals_closed_count

ROI %:
  (net_profit / spend) × 100

YTD Achievement %:
  (ytd_revenue / ytd_target) × 100
