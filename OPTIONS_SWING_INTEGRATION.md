## MANAGING OPTION POSITIONS

### Daily Monitoring

```
Each option position needs:
├─ Entry price and date
├─ Max profit target (when to sell 100%)
├─ 50% profit target (sell half at +50%)
├─ Stop loss (-30% of premium = EXIT)
├─ Days to expiration (monitor decay)
└─ Daily P&L update

Position tracking:
├─ NVDA call spread: Entry $5 cost, now worth $8 = +$300 profit
├─ APPS call spread: Entry $0.40, now worth $0.55 = +$45 profit
├─ Exit when: Max profit hit OR -30% loss OR 1 day before expiration
```

### Exit Rules

**Take profit rule:**
```
Spread hits 50% max profit = Sell HALF
├─ Locks in wins
├─ Keeps half for "free" (risk-free)
├─ Reduces theta decay impact

Example NVDA spread:
├─ Max profit: $2,000
├─ At $1,000 profit (50%): SELL HALF (1 spread, get back $1,000)
├─ Keep 1 spread running for other half
└─ Now "playing with free money"
```

**Stop loss rule:**
```
Loss hits -30% = EXIT IMMEDIATELY
├─ No holding losers (theta kills you)
├─ Cut losses fast
├─ Preserve capital

Example APPS spread:
├─ Cost: $40
├─ Loss trigger: -$12 (-30%)
├─ Stop loss price: $0.28 (from $0.40 entry)
└─ EXIT if hit
```

**Time decay rule:**
```
1 day before expiration = CLOSE position
├─ Risk explosion from gamma/theta
├─ Take whatever profit/loss exists
├─ Roll to next week if still valid

Example:
├─ Bought 3-week call spread
├─ Day 18: Still profitable, keep running
├─ Day 20: 1 day to expiration, CLOSE (take $500 profit)
└─ Don't risk overnight decay
```
