QUICK USAGE:
  
  # Validate all gates in parallel
  import asyncio
  from agents.agent_risk_gates import AgentRiskGates
  
  gates = AgentRiskGates()
  report = await gates.validate_all_gates()
  print(f"Pass: {report.validation_pass}")
  print(f"Critical: {report.critical_failures}")
  
  # Validate single gate
  result = gates.validate_single("llm_cost_control")
  print(result.message)

KEY FEATURES:
  ✓ Parallel execution via asyncio.gather()
  ✓ All 13 gates run concurrently (~50-100ms total)
  ✓ Timeout protection (30s configurable)
  ✓ JSON serializable results
  ✓ Severity-based blocking logic
  ✓ Exception resilience
  ✓ Per-gate execution timing

RETURN STRUCTURE:

  ValidationReport:
    - timestamp: ISO 8601
    - total_gates: 13
    - passed: count
    - failed: count
    - warned: count
    - skipped: count
    - critical_failures: count
    - validation_pass: bool (True if critical_failures=0 and failed=0)
    - total_execution_time_ms: float
    - results: List[GateResult]
  
  GateResult:
    - gate_id: str
    - gate_name: str
    - status: GateStatus (PASS/FAIL/WARN/SKIP)
    - severity: GateSeverity (CRITICAL/HIGH/MEDIUM/LOW)
    - message: str (human readable)
    - details: dict (validation details)
    - timestamp: ISO 8601
    - execution_time_ms: float
