## FAQ

### Q: What if we miss a day's milestone?
**A**: No single day is critical. If you miss Day 8 video publishing, publish on Day 9–10 and adjust schedule. The week's target (e.g., 15 videos published) is what matters.

### Q: What if sponsorship deals don't close?
**A**: Switch to affiliate-heavy strategy (Week 2 was 2:1 affiliate:sponsorship if needed). Sponsorship is high-upside but uncertain; affiliate is reliable baseline.

### Q: Can we run all 4 revenue streams in parallel?
**A**: Yes, but sequentially better for learning. Week 2 focuses on YouTube+sponsorship (1–2 hours/day coordination). Week 3 adds API Premium (30 min backend setup). Week 4 adds consulting (2 hours/day sales time). By Week 4, all 4 run simultaneously (8h/day).

### Q: What's the minimum viable Phase 2?
**A**: If budget/time is constrained:
- Week 2: YouTube + affiliate only (drop sponsorship, skip social expansion)
- Week 3: API Premium only (skip affiliate expansion)
- Week 4: Consulting only (drop API upsell)
- **Expected outcome**: $1,500–$3,000 month 1 (still profitable)

### Q: How much budget does Phase 2 require?
**A**: $0 hard costs. All platforms free (YouTube, TikTok, Instagram, Stripe).
- **Time cost**: 168 hours (team salaries)
- **Opportunity cost**: Could use time on other projects

### Q: When should we pause/pivot?
**A**: 
- **If by Day 14**: Revenue < $200 + sponsorship response < 10% → Pivot to affiliate-only
- **If by Day 21**: API signups < 15 + affiliate flat → Drop API, focus on consulting
- **If by Day 28**: Total revenue < $2,000 → Phase 2 failed; retrospective needed
