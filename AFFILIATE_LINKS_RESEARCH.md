### **Step 3: JSON Configuration Format**

Once you secure affiliate links, format them as:

```json
{
  "AFFILIATE_LINKS": {
    "stripe": "https://referral.stripe.com/...",
    "openai": "https://platform.openai.com/...ref...",
    "zapier": "https://zapier.com/partners/...",
    "convertkit": "https://convertkit.com/?ref=...",
    "amazon": "tag=alreadyhere-20",
    "vercel": "https://vercel.com/...",
    "aws": "https://aws.amazon.com/...",
    "make": "https://make.com/invite/...",
    "notion": "https://notion.so/?ref=..."
  }
}
```

Then set in Vercel → Environment Variables as:
- Name: `AFFILIATE_LINKS`
- Value: (copy the JSON above, formatted single-line)
