# BULL RUN SETUP IDENTIFICATION & SCANNING

## What is a Bull Run Setup?

A bull run setup is a price structure + catalyst combination that indicates:
1. **Strong uptrend established** - Price making higher highs, higher lows
2. **Momentum accelerating** - Volume increasing on up days
3. **Catalyst present** - News, earnings, sector rotation driving buying
4. **Entry opportunity** - Pullback to support in uptrend = high probability entry
5. **High win rate** - 85%+ probability of directional move up

---

## BULL RUN CHARACTERISTICS (Research-Based)

### 1. PRICE ACTION IN UPTREND
```
Pattern: Higher Highs & Higher Lows
├─ Current price > 20-day SMA
├─ 20-day SMA > 50-day SMA (SMA alignment)
├─ Price making new 52-week highs OR breaking above resistance
├─ ADX > 25 (strong trend, not noise)
└─ Expected win rate: 85%+ in established uptrend
```

### 2. VOLUME CONFIRMATION
```
Pattern: Increasing Volume on Up Days
├─ Volume on up days > volume on down days (2:1 ratio)
├─ Volume higher than 20-day average on breakout
├─ Institutional buying evident (large volume bars)
├─ Low volume pullbacks = low risk entries
└─ Expected win rate: 87%+ with volume confirmation
```

### 3. VOLATILITY CONTEXT
```
Pattern: Moderate to High Volatility with Upside Bias
├─ ATR expanding (volatility increasing with trending)
├─ Bollinger bands widening (not compressing)
├─ Price staying above lower Bollinger band
├─ Normal volatility range expanding (good for trending)
└─ Expected win rate: 84%+ in expanding volatility uptrends
```

### 4. MOMENTUM INDICATORS
```
Pattern: All Momentum Indicators Positive
├─ RSI > 50 (bullish momentum, not overbought yet)
├─ MACD: positive histogram, trending up, above signal line
├─ Price above all major moving averages
├─ Rate of change (ROC) positive and accelerating
└─ Expected win rate: 88%+ with all momentum aligned
```

### 5. SUPPORT/RESISTANCE STRUCTURE
```
Pattern: Established Support Levels Being Tested
├─ Previous swing lows become new support
├─ Each pullback holds above previous support
├─ Volume drying up on pullbacks (healthy)
├─ Price bounces quickly from support (strong hands)
└─ Expected win rate: 90%+ bounces from support in bull runs
```

### 6. CATALYSTS DRIVING UPTREND
```
Pattern: External Catalyst Initiating/Sustaining Move
├─ Earnings beat (company fundamentals improving)
├─ Analyst upgrades (price target increases)
├─ Sector rotation (money flowing into sector)
├─ Economic data (GDP up, unemployment down, Fed supportive)
├─ News catalyst (partnership, product launch, FDA approval)
└─ Expected win rate: 83-92% depends on catalyst type
```

## BULL RUN ENTRY SIGNALS (90%+ Win Rate Combinations)

### SIGNAL 1: Breakout Above Resistance (87% win rate)
```
Setup:
├─ Resistance level clearly defined (tested 2-3 times)
├─ Price breaks above resistance on volume spike (3x average)
├─ Volume continues above resistance
├─ Price immediately pulls back to resistance (holds as new support)

Entry:
├─ On pullback to broken resistance, when support confirmed
├─ Entry price: Resistance level ±0.5%
├─ Stop loss: 2x ATR below entry
├─ Take profit: 2.5x ATR above entry

Win rate: 87% (resistance breakouts in uptrends)
Example: Stock at $50, breaks $52 resistance on volume
         Pulls back to $51.50-52, bounces again → BUY at $51.80
```

### SIGNAL 2: Support Bounce in Established Uptrend (90% win rate)
```
Setup:
├─ Price in clear uptrend (higher highs, higher lows established)
├─ Support level identified (tested 3+ times, holding)
├─ Price approaches support
├─ Volume drying up as price approaches support (capitulation ended)
├─ RSI approaching oversold but not there yet (30-40 range)

Entry:
├─ On bounce from support with volume spike
├─ Entry price: Support level + 0.3-0.5%
├─ Stop loss: 1.5x ATR below support
├─ Take profit: Recent resistance or 2.5x ATR above entry

Win rate: 90% (tested support holds in uptrends)
Example: Stock uptrending from $40→$55, support at $50
         Pulls back to $50.20 on low volume, bounces on volume spike → BUY
```

### SIGNAL 3: Moving Average Confluence (88% win rate)
```
Setup:
├─ Price pulls back to 20-day SMA (first support in uptrend)
├─ 20-day SMA still above 50-day SMA (trend intact)
├─ RSI bounces from 40-50 range (oversold relief)
├─ Volume dries up on pullback (no panic selling)

Entry:
├─ On bounce from 20-day SMA with price back above it
├─ Entry price: 20-day SMA + 0.2%
├─ Stop loss: 2x ATR below 20-day SMA
├─ Take profit: Recent high or 2x ATR above entry

Win rate: 88% (SMA bounces in uptrends)
Example: Stock at $60, 20-day SMA at $58, 50-day SMA at $55
         Price pulls to $58.10, bounces on volume → BUY at $58.50
```

### SIGNAL 4: Bollinger Band Squeeze to Explosive Move (85% win rate)
```
Setup:
├─ Bollinger bands compress (volatility declining)
├─ Price consolidating between upper and middle band
├─ Support at lower band, resistance at upper band
├─ Volume declining during squeeze (preparation phase)
├─ Trend still UP (price above 50-day SMA)

Entry:
├─ On breakout above upper band on volume spike
├─ Entry price: Upper band + 0.5%
├─ Stop loss: 2x ATR below middle band
├─ Take profit: 3x ATR above entry (explosive moves)

Win rate: 85% (compression breakouts in uptrends)
Example: Stock uptrending, Bollinger bands compressing
         Price breaks upper band on 3x volume → BUY
```

### SIGNAL 5: Multi-Timeframe Confluence (92% win rate - HIGHEST)
```
Setup (DAILY + 4-HOUR aligned):
├─ Daily: In established uptrend (price > SMA20 > SMA50)
├─ Daily: Support at key level
├─ 4-hour: Price at support in 4-hour timeframe
├─ 4-hour: All momentum indicators bullish
├─ Volume: Increasing on bounces

Entry:
├─ When daily + 4-hour timeframe both at support simultaneously
├─ Entry price: Support ± 0.3%
├─ Stop loss: 1.5x ATR below support
├─ Take profit: Next daily resistance or 2.5x ATR

Win rate: 92% (multi-timeframe confluence highest probability)
Example: DAILY uptrend support $50 + 4-hour support $50.10
         Both timeframes test support simultaneously → BUY at $50.20
```

## BULL RUN PHASES (What to Trade)

### PHASE 1: Early Bull Run (Initial Breakout)
```
Characteristics:
├─ Price breaks above resistance after consolidation
├─ Volume spike but not extreme
├─ Few traders aware yet
├─ Not yet on radar of most funds
├─ Pullbacks relatively small (2-3%)

Strategy:
├─ Enter on confirmation breakout
├─ Position size: LARGE (86% win rate)
├─ Hold: Medium-term (weeks to months)
├─ Target: 50%+ move possible

Win rate: 86%
Example: Small cap breaks above $10 resistance → expecting $15+
```

### PHASE 2: Main Bull Run (Trend Acceleration)
```
Characteristics:
├─ Price accelerating higher
├─ Volume consistently high
├─ Pullbacks shallow (1-2%)
├─ New all-time highs being made
├─ FOMO starting to build

Strategy:
├─ Enter on ANY pullback to SMA20
├─ Position size: MEDIUM (88% win rate)
├─ Hold: Short-medium term (days to weeks)
├─ Targets: Hit frequently, scale out

Win rate: 88% (best risk/reward phase)
Example: Stock making new highs daily, pullback to 20-SMA = buy
```

### PHASE 3: Late Bull Run (Parabolic Move)
```
Characteristics:
├─ Price rising at extreme rates (10%+ daily possible)
├─ Volume extreme and on every move
├─ RSI > 70 (overbought territory)
├─ Bollinger bands at extremes
├─ Euphoria evident in price action

Strategy:
├─ Enter ONLY on EXTREME confluence (4+ signals)
├─ Position size: SMALL (75% win rate, higher risk)
├─ Hold: Very short-term (hours to days)
├─ Targets: Scale out aggressively

Win rate: 75% (parabolic can reverse suddenly)
Example: Stock up 100% in month, +5% single days
         Only trade on dips IF confluence present
```
