## ✅ STEP 3: BUILD THE APP

1. **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Wait for "Build successful" message
3. APK created at: `app/build/outputs/apk/debug/app-debug.apk`

---

## ✅ STEP 4: RUN ON EMULATOR

1. **Device Manager** (right panel) → Create emulator if needed
2. Click **Play** to start emulator
3. **Run → Run 'app'**
4. Select emulator → Click **OK**
5. Wait 30 seconds for app to launch
