## THREE LAYERS: STOCK vs SWINGS vs OPTIONS

### Layer 1: Stock Trading (Safe, Slow)

```
Strategy: Buy stock on swing signal, hold 2-5 days

Example NVDA: Buy at $850
├─ If rises to $918 (+8%): Profit $68 = 8% ROI
├─ If falls to $800: Loss $50 = -5.8% loss
├─ Hold time: 2-4 days
└─ Risk/reward: 1:1.4 (modest)

Pros:
├─ No options knowledge needed
├─ Simple entry/exit
├─ Can hold longer if wrong
└─ Sleep well at night

Cons:
├─ Slow ROI (8% in 2 days)
├─ Must own full stock ($850)
├─ Requires full capital allocation
└─ Annual ROI ~50% if repeated
```

### Layer 2: Swing Trading with Calls/Puts (Balanced)

```
Strategy: Call spread on swing signal

Example NVDA: Buy $850/$870 call spread for $500
├─ If rises to $918: Profit $1,500 = 300% ROI
├─ If falls to $800: Loss $500 = -100% loss
├─ Hold time: 2-4 days
└─ Risk/reward: 1:3 (excellent)

Pros:
├─ 300% ROI in 2-4 days (exceptional)
├─ Defined risk (max loss $500)
├─ Smaller capital requirement
├─ Spreads have 70-75% win rate
└─ Annual ROI ~500%+ if repeated

Cons:
├─ Need options knowledge
├─ Theta decay works against you
├─ Require broker with options
├─ Need to monitor position
```

### Layer 3: Leveraged Trading (Most Aggressive)

```
Strategy: Long call on high-confidence (95%+) signal

Example NVDA: Buy $850 call for $10 (cost $1,000)
├─ If rises to $918: Profit $5,800 = 580% ROI
├─ If falls to $800: Loss $1,000 = -100% loss
├─ Hold time: 2-4 days
└─ Risk/reward: 1:5.8 (massive)

Pros:
├─ 580% ROI in 2-4 days (incredible)
├─ Huge leverage on capital
├─ Small absolute dollar risk
└─ Annual ROI 2,000%+ possible

Cons:
├─ All-or-nothing feel (full loss possible)
├─ High stress watching positions
├─ Theta decay accelerates losses
├─ Requires very high confidence
└─ Win rate lower (55-65%)
```
