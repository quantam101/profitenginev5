## DESIGN NOTES FOR CANVA

### Universal Design Guidelines

1. **Image Size**: 1080 x 1350 pixels (all slides)
2. **Safe Text Area**: Leave 100px margin on all sides
3. **Typography**:
   - Titles: 60-80pt, bold, sans-serif (Montserrat, Proxima Nova, or similar)
   - Key points: 32-40pt, medium weight
   - Captions: 24-28pt, light weight
4. **Color Palette**:
   - Primary: #0f3460 (dark trading blue)
   - Secondary: #16213e (slightly lighter blue)
   - Accent: #FFD700 (gold for important numbers)
   - Success: #2ECC71 (green for wins)
   - Warning: #FF6B6B (red for risks)
   - Text: #FFFFFF (white on dark backgrounds)

5. **Element Consistency**:
   - Use same fonts across all 3 carousels
   - Consistent color scheme (dark blue base + gold/green/red accents)
   - Slide numbers visible (1/7, 2/7, etc.) in corner
   - ProfitEngine branding on Slide 7 of each carousel

6. **Spacing**:
   - 40-50px padding inside text boxes
   - 20-30px gap between elements
   - Center-aligned for titles, left-aligned for bullets

7. **Visual Elements**:
   - Use actual trading charts/screenshots where possible (adds credibility)
   - Icons should be clean, minimal, trading-related
   - Avoid stock photos unless necessary
   - Use backgrounds/gradients for visual interest, not distraction
