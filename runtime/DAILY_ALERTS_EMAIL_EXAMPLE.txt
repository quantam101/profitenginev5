WHAT THE SYSTEM DOES:
================================================================================

1. QUERIES CLIENTS.DB (read-only):
   - Top performers by P&L and win rate today
   - New signups from past 24 hours
   - Clients ready for premium upgrades (win rate >= 70%)
   - Database integrity check

2. FORMATS PROFESSIONAL EMAIL:
   - HTML version (rich formatting, tables, colors)
   - Plain text fallback (mobile-friendly)
   - Mobile-responsive design
   - Professional branding

3. SENDS VIA:
   - Gmail SMTP (simplest)
   - SendGrid API (high volume)
   - AWS SES (enterprise)
   - Telegram optional (real-time alerts)
   - Slack optional (team notifications)

4. LOGS EVERYTHING:
   - Email delivery status
   - Timestamps
   - Recipient address
   - Any errors


TIME SCHEDULE:
================================================================================

Default: Every day at 5 PM MST (market close)

During Daylight Saving Time (roughly March-November):
  5 PM MST = 23:00 UTC = 23:00 Coordinated Universal Time

During Standard Time (roughly November-March):
  6 PM MST = 00:00 UTC next day = 00:00 Coordinated Universal Time

Note: "MST" (Mountain Standard Time) is used year-round, though actual
offset changes with daylight saving. The system uses UTC times for reliability.

UPSELL SCORING LOGIC:
================================================================================

Top Performers Criteria:
  1. Orders by Daily P&L (highest first)
  2. Ties broken by win rate
  3. Top 5 selected

Upsell Candidates Criteria:
  - Minimum 20 total trades (to qualify)
  - Win rate >= 70% → Hybrid Tier candidate
  - Win rate >= 85% → White-Label / Enterprise candidate
  - Daily P&L > $500 → High-value customer signal
  - 10+ winning trades → Engagement signal

New Signups Criteria:
  - Accounts created within last 24 hours
  - Shows today's trading activity if any

System Health Criteria:
  - Healthy: > 0 clients, > 0 trades in system
  - Degraded: Clients or trades missing
  - Error: Database connection failure


DATABASE QUERIES:
================================================================================

1. Daily P&L Summary:
   SELECT SUM(pnl_usd), COUNT(*), COUNT(DISTINCT client_id)
   FROM trades
   WHERE DATE(executed_at) = TODAY

2. Top Performers:
   SELECT * FROM clients LEFT JOIN trades
   WHERE DATE(traded.executed_at) = TODAY
   ORDER BY daily_pnl DESC, win_rate DESC
   LIMIT 5

3. New Signups:
   SELECT * FROM clients
   WHERE created_at > NOW() - 1 DAY
   ORDER BY created_at DESC

4. Upsell Candidates:
   SELECT * FROM clients
   WHERE total_trades >= 20
   AND (win_rate >= 0.70 OR daily_pnl > 500 OR winning_trades >= 10)
   LIMIT 10

5. Database Health:
   SELECT COUNT(*) FROM clients
   SELECT COUNT(*) FROM trades

ERROR HANDLING:
================================================================================

If Email Provider Fails:
  - Logs error with full details
  - Never crashes the system
  - Retries transient errors (network timeouts)
  - Telegram/Slack still sent if configured

If Database Query Fails:
  - Uses cached data or empty results
  - Marks health as "error"
  - Still sends email (with error noted)
  - Full error logged

If Credentials Missing:
  - Gracefully skips that provider
  - Logs warning
  - Falls back to next provider
  - Eventually fails with no-provider error

All errors logged to:
  daily_alerts.log


CUSTOMIZATION OPTIONS:

  Edit EmailTemplates.daily_alert_html() and _text()

Add Notification Channel:
  Implement function following send_telegram_alert() pattern

Filter Top Performers:
  Adjust get_top_performers(limit=5) parameter

Change Upsell Thresholds:
  Edit get_upsell_candidates() win rate % and thresholds
