================================================================================
WHAT IT DOES
================================================================================

Generates professional marketing content automatically from daily trading data:

1. BLOG POSTS (Markdown)
   - Daily results with statistics
   - Top 3 traders profile
   - Best performing strategy analysis
   - Key insights & learnings
   - Tier upgrade CTAs
   Ready for: WordPress, Medium, Dev.to, GitHub Pages

2. TWEETS (5 variations)
   - Win rate focus
   - Best strategy highlight
   - Daily P&L + new customers
   - System reliability message
   - Call-to-action
   All <280 characters

3. PERSONALIZED EMAILS (HTML + Plain Text)
   - Individual performance summary
   - 30-day metrics
   - Performance assessment
   - Tier-specific CTAs
   - Quick action links
   One email per customer

4. MILESTONE CONTENT (Special Events)
   - $1,000 profit achievement
   - 90%+ win rate reach
   - Tier upgrade congratulations
   High-priority delivery

5. CASE STUDIES (HTML)
   - Top 3 performers by lifetime P&L
   - Trading journey overview
   - Performance metrics grid
   - Success factors
   - ROI highlights
   Ready for landing pages

================================================================================
RUNNING DAILY (AUTOMATED)
================================================================================

Option A: Linux/macOS Cron
  crontab -e
  Add: 30 17 * * * cd /path/to/runtime && python content_generator.py >> content_generator.log 2>&1

  This runs at 5:30 PM MST every day

Option B: systemd Timer (Linux)
  See CONTENT_GENERATOR_SETUP.md for full systemd instructions

Option C: Windows Task Scheduler
  Run PowerShell as admin:
  $action = New-ScheduledTaskAction -Execute "python.exe" -Argument "content_generator.py" -WorkingDirectory "C:\path\to\runtime"
  $trigger = New-ScheduledTaskTrigger -Daily -At 5:30PM
  Register-ScheduledTask -TaskName "ProfitEngine Content Generator" -Action $action -Trigger $trigger

QUICK COMMANDS
================================================================================

Generate content for today:
  python content_generator.py

Generate for specific date:
  python content_generator.py --date 2026-06-18

Dry-run (no files saved):
  python content_generator.py --dry-run

Verbose logging:
  python content_generator.py --verbose

Run tests:
  python test_content_generator.py -v

Check today's blog post:
  cat output/blog_posts/blog-post-$(date +%Y-%m-%d).md

Count emails generated:
  ls output/emails/$(date +%Y-%m-%d)/*.html | wc -l

View recent log:
  tail -50 content_generator.log

Check for errors:
  grep ERROR content_generator.log
