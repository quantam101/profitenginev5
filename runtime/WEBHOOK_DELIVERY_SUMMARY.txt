├─ id: INTEGER PRIMARY KEY
├─ trade_id: TEXT UNIQUE NOT NULL

├─ symbol: TEXT NOT NULL
├─ side: TEXT NOT NULL (buy/sell)
├─ quantity: REAL NOT NULL

├─ exit_price: REAL
├─ entry_time: TEXT NOT NULL

├─ commission: REAL DEFAULT 0.0
├─ created_at: TEXT NOT NULL
└─ updated_at: TEXT NOT NULL

balance_history (Account Changes)
├─ id: INTEGER PRIMARY KEY
├─ user_id: INTEGER NOT NULL
├─ previous_balance: REAL NOT NULL
├─ current_balance: REAL NOT NULL
├─ change_amount: REAL NOT NULL
├─ available_cash: REAL
├─ margin_used: REAL
└─ timestamp: TEXT NOT NULL

alerts (Triggered Alerts)

├─ message: TEXT NOT NULL

├─ current_value: REAL
├─ triggered_at: TEXT NOT NULL

INTEGRATION OPTIONS
================================================================================

OPTION 1: Mount as Router (Recommended)
├─ In runtime/api.py:
│  from robinhood_webhook_handler import app as webhook_app
│  app.include_router(webhook_app.router, prefix="/webhooks")
├─ Start: uvicorn runtime.api:app
└─ Endpoints: http://localhost:8000/webhooks/...

OPTION 2: Mount as Sub-Application
├─ In runtime/api.py:
│  app.mount("/webhooks", webhook_app)
├─ Start: uvicorn runtime.api:app
└─ Endpoints: http://localhost:8000/webhooks/...

OPTION 3: Separate Service
├─ Run on port 8001: uvicorn robinhood_webhook_handler:app --port 8001
├─ Use reverse proxy (nginx) to route /webhooks
└─ Endpoints: https://yourdomain.com/webhooks/...
