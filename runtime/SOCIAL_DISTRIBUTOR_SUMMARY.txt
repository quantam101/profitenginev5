================================================================================
API ENDPOINTS
================================================================================

POST /api/social/distribute
  → Distribute content to multiple platforms
  → Input: content_id, title, body, link, platforms, hashtags, media
  → Returns: {ok: bool, results: {platform: success}}

GET /api/social/posts?platform=X&status=Y
  → List posts by platform and status
  → Returns: {ok: bool, posts: [...]}

GET /api/social/engagement?days=7&limit=5
  → Get top posts by engagement
  → Returns: {ok: bool, total_engagement: int, top_posts: [...]}

POST /api/social/digest?recipient=email@example.com
  → Send email digest manually
  → Returns: {ok: bool, message: string}
