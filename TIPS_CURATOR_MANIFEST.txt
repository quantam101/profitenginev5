1. Copy config template:
   cp scripts/tips_curator.env.example .env.tips

2. Edit .env.tips with your API keys:
   GROQ_API_KEY=gsk_...
   GITHUB_CONTENT_TOKEN=ghp_...

   TIPS_VERIFY_ONLY=true python scripts/tips_curator.py

4. Extract tips:
   python scripts/tips_curator.py --extract --format all --ebook

5. Check outputs:
   ls -la data/tips/

REQUIRED:
  GROQ_API_KEY                    Groq LLM API key (free from console.groq.com)
  GITHUB_CONTENT_TOKEN            GitHub PAT (from github.com/settings/tokens)
  GITHUB_CONTENT_OWNER            Repo owner (e.g., quantam101)
  GITHUB_CONTENT_REPO             Repo name (e.g., content)

OPTIONAL (Social Publishing):
  TWITTER_API_KEY                 From developer.twitter.com
  TWITTER_API_SECRET
  TWITTER_ACCESS_TOKEN
  TWITTER_ACCESS_SECRET

  LINKEDIN_ACCESS_TOKEN           From linkedin.com/developers
  LINKEDIN_PERSON_URN

  INSTAGRAM_ACCESS_TOKEN          From developers.facebook.com
  IG_USER_ID

  GUMROAD_ACCESS_TOKEN            From gumroad.com/settings

MONETIZATION:
  AFFILIATE_LINKS                 JSON map {"zapier": "url", ...}
  AMAZON_PARTNER_TAG              (default: alreadyhere-20)
  MONETIZATION_ENABLED            true/false (default: true)

OUTPUT:
  TIPS_OUTPUT_DIR                 Where to save tips (default: data/tips)
  TIPS_EBOOK_CHAPTERS             Number of chapters (default: 5)
