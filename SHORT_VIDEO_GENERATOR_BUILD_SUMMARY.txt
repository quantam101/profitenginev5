================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

PROBLEM: "ffmpeg: command not found"
SOLUTION: Install FFmpeg (ubuntu: sudo apt-get install ffmpeg)

PROBLEM: "espeak: command not found"
SOLUTION: Install espeak (ubuntu: sudo apt-get install espeak)

PROBLEM: "Voice-over generation failed"
SOLUTION: Install gTTS (pip install gtts) or ensure espeak works

PROBLEM: Videos generating slowly
SOLUTION: Normal (1-2 min per format). Use --no-music to speed up.

PROBLEM: Audio quality is low
SOLUTION: Install gTTS (pip install gtts) for better voice quality

For more detailed troubleshooting:
→ See SHORT_VIDEO_GENERATOR_README.md "Troubleshooting" section
→ Check inline comments in short_video_generator.py
→ Run examples to verify system is working
