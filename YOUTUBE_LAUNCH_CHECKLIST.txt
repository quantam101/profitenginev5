================================================================================

UPLOAD FAILS?

  2. Delete failed video
  3. Wait 5 minutes (cache clears)
  4. Re-upload with same metadata
  5. If persistent: Try different browser (incognito)

SCHEDULE WON'T SAVE?
  1. Verify date is AFTER today (never past dates)
  2. Timezone: Always use PT (avoid ambiguity)
  3. Click "Schedule" again
  4. Check status changed to "Scheduled"

THUMBNAIL WON'T UPLOAD?
  1. Convert to JPG (if PNG causing issues)
  2. Verify 1280×720px exactly
  3. Verify <2MB file size
  4. Try saving locally first (not from browser)
  5. Clear browser cache, retry

LINKS BREAK IN DESCRIPTION?
  1. Go to About → Edit
  2. Remove any emoji or special characters
  3. Paste links as plain text (no markup)
  4. Click Save
  5. Wait 5 minutes for propagation
