## ROLLBACK / EMERGENCY PROCEDURES

### If Video Upload Fails
1. Go to Studio → Uploads
2. Click failed video → **Delete**
3. Wait 5 minutes (ensure cache clears)
4. Re-upload with same metadata
5. If persistent: Try different browser/incognito

### If Schedule Doesn't Take
1. Go to video draft
2. Click **More options** → **Schedule**
3. Ensure date is **after today** (never past dates)
4. Timezone: Always use **PT** (avoid ambiguity)
5. Click **Schedule** again
6. Verify status changes to "Scheduled"

### If Thumbnail Doesn't Upload
1. Convert to JPG (if PNG)
2. Verify dimensions: 1280×720px exactly
3. Verify file size: <2 MB
4. Try different image (saved locally, not from browser)
5. Clear browser cache & retry

### If Channel Description Breaks Links
1. Go to About → Edit
2. Check for forbidden characters (emoji, special chars)
3. Paste links as plain text (no markup)
4. Click Save
5. Verify links clickable after 5-minute propagation
