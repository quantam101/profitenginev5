## QUICK DECISION TREE

```
IF open rate < 30% on Day 5:
→ Subject lines may have failed
→ ACTION: Refresh subject lines for Day 6-7 follow-ups

IF reply rate < 15% after Day 7:
→ Messaging may not resonate
→ ACTION: A/B test new CTA (call vs. demo vs. question)

IF < 2 calls scheduled by Day 7:
→ Normal for Tier 2-3, but follow up hard
→ ACTION: Call top 3 leads directly (phone) instead of email

IF Tier 3 shows zero interest:
→ C-level needs warm intros first
→ ACTION: Pause cold Tier 3, focus on Tier 1-2 wins first

IF unexpected high engagement:
→ Prioritize top prospects, accelerate calls to Week 1 if possible
→ ACTION: Propose calls for June 28-29 (before standard Week 2)
```
