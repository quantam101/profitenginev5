🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ERROR: "Missing required secrets"
  → Add secrets to GitHub: Settings → Secrets → Actions

ERROR: Instagram posts not appearing
  → Check token validity (use long-lived token)
  → Verify business account permissions

ERROR: Email not sending
  → Verify EMAIL_PLATFORM matches provider (klaviyo/substack/convertkit)
  → Check API key is correct

ERROR: Workflow hangs
  → Check if external APIs are down
  → Increase timeout in workflow file

Need more help?
  → See AUTOMATION_README.md (Troubleshooting section)
  → Check Slack #automation-alerts for error details

📋 API KEYS REQUIRED (8 TOTAL)
═══════════════════════════════════════════════════════════════════════════

1. GUMROAD_API_KEY
   From: https://app.gumroad.com → Settings → Advanced → API
   Time: 3 minutes

2. INSTAGRAM_ACCESS_TOKEN
   From: Meta Business Manager → System Users → Generate Token
   Time: 10 minutes

3. INSTAGRAM_BUSINESS_ACCOUNT_ID
   From: Meta Business Manager → Instagram Accounts
   Time: 1 minute

4. REPLICATE_API_TOKEN (or DALLE_API_KEY)
   From: https://replicate.com → Account → API tokens
   Time: 5 minutes

5. SYNTHESIA_API_KEY (optional for video)
   From: https://synthesia.io → Integrations → API
   Time: 5 minutes

6. ELEVEN_LABS_API_KEY (optional for voiceover)
   From: https://elevenlabs.io → Account → API Key
   Time: 3 minutes

7. KLAVIYO_API_KEY (or SUBSTACK/CONVERTKIT key)
   From: Email platform settings
   Time: 5 minutes

8. GITHUB_ACTIONS_TOKEN
   From: https://github.com/settings/tokens → Generate token
   Time: 2 minutes

9. SLACK_WEBHOOK_URL (optional but recommended)
   From: https://api.slack.com → Your App → Incoming Webhooks
   Time: 2 minutes

Total time: ~35 minutes
