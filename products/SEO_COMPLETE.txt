SECTION 3: 20-POINT ON-PAGE OPTIMIZATION CHECKLIST
==================================================

TECHNICAL SEO:
☐ URL contains main keyword (under 75 characters)
☐ Title tag < 60 characters
☐ Keyword in first 40 characters of title
☐ Meta description < 160 characters, includes keyword and CTA
☐ Only one H1 tag per page
☐ H1 contains main keyword
☐ Mobile-friendly (test on mobile)
☐ Page loads < 3 seconds
☐ Schema markup implemented (LocalBusiness or Article)

CONTENT QUALITY:
☐ Word count > 1000 words (for competitive keywords)
☐ Main keyword density 0.5-1.5%
☐ LSI keywords (synonyms) used naturally
☐ Content answers search intent completely
☐ No duplicate content (plagiarism check)
☐ Original, fresh content

STRUCTURE & READABILITY:
☐ Proper heading hierarchy (H1 > H2 > H3)
☐ Short paragraphs (3-4 sentences max)
☐ Bullet points for lists
☐ 3-5 internal links to relevant content
☐ Clear call-to-action above the fold
☐ Links use descriptive anchor text (not "click here")

SECTION 4: INTERNAL LINKING STRATEGY
===================================

WHY INTERNAL LINKS MATTER:
- Pass authority from high-ranking to new pages
- Help Google understand site structure
- Keep visitors on site longer
- Establish topical authority
- Improve indexation of new content

BEST PRACTICES:
✓ Link from high-authority pages to new pages
✓ Use keyword-rich anchor text (natural language)
✓ Link contextually (related content to related)
✓ 3-5 internal links per 1000 words
✓ Use natural, readable language

INTERNAL LINKING EXAMPLES:

If you rank for: "Best plumber in Denver"
Link to: "Emergency plumbing services Denver" (related service)
Link to: "How to find a plumber" (related question)
Link to: "Plumbing repair costs Denver" (related question)

If you rank for: "Content marketing guide"
Link to: "Email marketing strategy" (related topic)
Link to: "SEO best practices" (related topic)
Link to: "Social media marketing" (related topic)

SECTION 5: SCHEMA MARKUP SNIPPETS (Copy-Paste Ready)
====================================================

LOCAL BUSINESS SCHEMA:
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "[BUSINESS_NAME]",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "[STREET]",
    "addressLocality": "[CITY]",
    "addressRegion": "[STATE]",
    "postalCode": "[ZIP]"
  },
  "telephone": "[PHONE]",
  "url": "[WEBSITE]",
  "image": "[LOGO_URL]"
}
```

ARTICLE SCHEMA:
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[HEADLINE]",
  "description": "[SHORT_DESCRIPTION]",
  "datePublished": "[PUBLISH_DATE]",
  "dateModified": "[LAST_UPDATE]",
  "author": {
    "@type": "Person",
    "name": "[AUTHOR_NAME]"
  }
}
```

REVIEW/RATING SCHEMA:
```json
{
  "@context": "https://schema.org/",
  "@type": "Review",
  "reviewRating": {
    "@type": "Rating",
    "ratingValue": "[RATING]",
    "bestRating": "5"
  },
  "reviewBody": "[REVIEW_TEXT]"
}
```
