## Week 2: YouTube + Sponsorship Risks

| YouTube videos don't gain traction (low views) | Medium (40%) | High | Have backup content ideas; focus on CTR optimization, not just views |
| Sponsorship outreach gets no responses | Medium (30%) | Medium | Expand to 20 prospects; use warm introductions; offer performance-based deals |
| API Premium development delays | Low (10%) | High | Have mock API endpoints ready; launch with 1 tier first, expand later |
| Affiliate programs not converting | Medium (35%) | Low | Switch programs; test different verticals; optimize landing page copy |

**Mitigation Playbook**:
- If sponsorship responses < 10% → Switch to affiliate-heavy strategy (skip sponsorship week 4)
- If YouTube views < 100/video → Pivot to TikTok/Instagram focus (better algorithms)
- If API Premium < 5 signups → Extend to free tier + premium upsell (freemium model)
