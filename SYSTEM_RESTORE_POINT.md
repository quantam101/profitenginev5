## How to Restore from This Point

### If System Fails
```bash
# 1. Get the backup
cd ~/profitengine-backups/
ls -lh

# 2. Extract
tar -xzf backup_YYYYMMDD.tar.gz

# 3. Restore code
cp -r YYYYMMDD/code/* /destination/

# 4. Decrypt secrets
gpg YYYYMMDD/secrets/.env.gpg

# 5. Restore database
mongorestore YYYYMMDD/databases/mongodb/

# 6. Redeploy
cd /destination
bash deploy_oci_hybrid.sh
```

### If OCI Dies
```bash
# 1. Spin up new OCI instance
# 2. SSH in
ssh ubuntu@NEW_IP

# 3. Clone repo
git clone https://github.com/quantam101/profitenginev5.git
cd profitenginev5

# 4. Deploy
bash deploy_oci_hybrid.sh

# 5. Verify
tail -f /home/ubuntu/video_generation.log
```

### If GitHub Dies
```bash
# 1. Get backup
tar -xzf ~/profitengine-backups/backup_*.tar.gz

# 2. Create new repo on GitHub
# 3. Push from backup
cd backup_dir/code
git remote set-url origin https://github.com/USERNAME/new-repo.git
git push origin main
```
