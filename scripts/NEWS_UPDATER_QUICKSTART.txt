================================================================================
  DAILY NEWS UPDATER — QUICK START GUIDE
================================================================================

WHAT IT DOES:
  Automatically curates business, AI, and passive income news daily from:
  - NewsAPI.org (10,000+ sources)
  - RSS feeds (TechCrunch, HackerNews, ProductHunt, etc.)
  - Trending topics analysis

  Then publishes to:
  ✅ Email newsletter (daily digest)
  ✅ Blog (SEO-optimized article)
  ✅ Twitter/Social media (tweet threads)
  ✅ Backend API (programmatic)

================================================================================
  SETUP (5 MINUTES)
================================================================================

Step 1: Get Free NewsAPI Key
  → Go to https://newsapi.org
  → Sign up (free tier: 100 requests/day)
  → Copy your API key

Step 2: Configure Environment
  Add to .env or GitHub Secrets:

  NEWSAPI_KEY=your_key_here
  PROFITENGINE_URL=https://profitengine-tau.vercel.app
  NEWSLETTER_API_KEY=your_newsletter_key  (optional)

Step 3: Install Dependencies

  pip install requests feedparser

Step 4: Test Preview

  python scripts/news_updater.py --action preview

================================================================================
  USAGE (3 COMMANDS)
================================================================================

1. PREVIEW (No Publishing)
   python scripts/news_updater.py --action preview

   Shows:
   - 5 Things to Know Today
   - Industry Updates
   - Trending Opportunities
   - Top stories


2. PUBLISH (Daily Update)
   python scripts/news_updater.py --action daily

   Publishes to:
   - Newsletter
   - Blog
   - Twitter
   - API


3. SAVE TO FILE (Debug/Review)
   python scripts/news_updater.py --action daily --output

   Saves output to: scripts/output/daily_news_*.json


SCHEDULE DAILY (Choose One):

Option A: GitHub Actions (Recommended)
  → Create .github/workflows/daily-news.yml (see README)
  → Set secrets: NEWSAPI_KEY
  → Runs automatically at 9 AM UTC

Option B: Cron Job (Linux/Mac)
  0 9 * * * cd /path/to/profitengine && python scripts/news_updater.py --action daily

Option C: Windows Task Scheduler
  Create task: python C:\path\news_updater.py --action daily
  Trigger: Daily at 9:00 AM

================================================================================
  CUSTOMIZATION
================================================================================

Add Custom RSS Feed:
  1. Edit news_updater.py
  2. In NewsAggregator.fetch_rss_feeds(), add to feeds dict:
     'My Feed': 'https://example.com/feed.rss',

Change Publication Time:
  1. GitHub Actions: Edit cron in .github/workflows/daily-news.yml
     From: 0 9 * * * (9 AM UTC)
     To:   0 17 * * * (5 PM UTC)

  2. Cron job: Edit crontab
     0 17 * * * python scripts/news_updater.py --action daily

Add Affiliate Links:
  1. Edit NewsFormatter._load_affiliate_links()
  2. Add your product:
     'Your Product': {
         'description': 'Product description',
         'url': 'https://your-affiliate-link.com',
         'commission': '10%'
     }

Custom Categories:
  1. Edit NewsCategory enum
  2. Add: YOUR_CATEGORY = "Display Name"
  3. Update _categorize_article() method

================================================================================
  TROUBLESHOOTING
================================================================================

Q: "NEWSAPI_KEY not configured"
A: Set environment variable:
   - Linux/Mac: export NEWSAPI_KEY=your_key
   - Windows: set NEWSAPI_KEY=your_key
   - GitHub: Add to Settings > Secrets > NEWSAPI_KEY

Q: "No news items aggregated"
A: Check:
   1. Internet connection
   2. NewsAPI key is valid
   3. API call limit not exceeded (free tier: 100/day)
   4. RSS feeds are accessible

Q: "Newsletter/Blog publish failed"
A: This is OK! Script still works:
   1. Script gracefully handles missing modules
   2. Check that newsletter_publisher.py exists
   3. Verify backend URL is correct
   4. Check API keys for each service

Q: "Slow execution"
A: Normal behavior:
   - NewsAPI: 3-5 seconds
   - RSS feeds: 3-5 seconds (6 feeds, timeout per feed)
   - Publishing: 10-30 seconds (depends on services)
   - Total: 15-40 seconds expected

Q: Can I run multiple times per day?
A: Yes! Schedule as many times as needed:
   - Cron: 0 9,12,15,18 * * * ... (run at 9 AM, noon, 3 PM, 6 PM)
   - GitHub: Add multiple schedule triggers
