  • Go to https://api.slack.com/apps

  • Add New Webhook to Workspace
  • Select channel (e.g., #profitengine-alerts)
  • Copy webhook URL (https://hooks.slack.com/services/...)

STEP 2: Run Setup Wizard

  Wizard will:
  • Ask for webhook URL (paste from Step 1)
  • Validate webhook works
  • Add GitHub secret PROFITENGINE_SLACK_WEBHOOK_URL
  • Show customization options

STEP 3: Test (Manual Trigger)
  • GitHub → Actions → "Slack Real-Time Monitoring"
  • Run workflow → Select "morning" / "evening" / "weekly"
  • Check Slack channel within 30 seconds

STEP 4: Done!

  • 8:00 AM UTC — Morning briefing
  • 6:00 PM UTC — Evening metrics

UPDATE REAL METRICS:
  Edit backend/services/slack_monitoring.py:

  async def _fetch_evening_metrics(self) -> list[MetricValue]:
      revenue = await self.db.daily_metrics.find_one()
      return [
          MetricValue(
              label="Daily Revenue",
              value=f"${revenue['total']:.2f}",
              status=StatusIndicator.OPERATIONAL,
              trend=f"↑ +{revenue['change']:.1f}%"
          )
      ]

ADD ALERTS:
  async def _fetch_evening_alerts(self) -> list[str]:
      alerts = []
      latency = await self.db.metrics.find_one({"metric": "latency"})
      if latency['value'] > 300:
          alerts.append(f"High latency: {latency['value']}ms")
      return alerts

CHANGE SCHEDULE:
  Edit .github/workflows/slack-monitoring.yml:

  schedule:
    - cron: "0 10 * * *"  # 10 AM instead of 8 AM
    - cron: "0 19 * * *"  # 7 PM instead of 6 PM
    - cron: "0 14 * * 0"  # Sunday 2 PM instead of 8 PM

TROUBLESHOOTING
================================================================================

Not posting?
  → Check PROFITENGINE_SLACK_WEBHOOK_URL GitHub secret
  → Verify webhook URL is correct
  → Test locally with curl
  → Check GitHub Actions logs

Wrong timezone?
  → Update cron in .github/workflows/slack-monitoring.yml (UTC)
  → See TIME ZONE QUICK REFERENCE above

Custom metrics not showing?
  → Update _fetch_*_metrics() in slack_monitoring.py
  → Connect to your database
  → Test locally: python -m backend.services.slack_monitoring
  → Commit and push (workflow auto-updates)

Test failed?
  → Run curl test above to validate webhook
  → Check Slack channel permissions
  → Verify webhook has permission to post

View logs?
  → GitHub Actions → Slack Real-Time Monitoring → Latest run
  → Check "Post * to Slack" step for error details
