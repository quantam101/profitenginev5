### 1.2 — SEO Infrastructure Checklist

#### Website Setup
- [ ] Domain purchased (if not, get one with trading keywords if possible: `[strategy]tradingguide.com`, `[strategy]academy.com`)

- [ ] XML sitemap generated and submitted to Google Search Console
- [ ] Google Search Console connected
- [ ] Google Analytics 4 installed
- [ ] Robots.txt configured
- [ ] Canonical tags implemented (prevent duplicate content)

#### Technical SEO
- [ ] Mobile-responsive design tested
- [ ] Page speed optimized (use Google PageSpeed Insights)
- [ ] Core Web Vitals targeted (<2.5s LCP, <100ms FID, <100ms CLS)
- [ ] Internal linking structure planned (see section 2.3)
- [ ] Breadcrumbs implemented
- [ ] Schema markup added (Article schema for blog posts)
- [ ] Duplicate content eliminated

#### Content Management
- [ ] CMS chosen (WordPress recommended for SEO flexibility, or Next.js/headless)
- [ ] Content calendar tool set up (Google Sheets or Airtable)
- [ ] SEO plugin installed (Yoast for WordPress, or manual schema)
- [ ] Keyword research tools subscribed (see section 5)
- [ ] Analytics dashboard created (track rankings, traffic, conversions)

### 1.3 — Internal Linking Structure

**Hub-and-Spoke Model:**
- **Hub (Pillar Pages):** 1 main page per strategy (e.g., `/swing-trading-guide`)
- **Spokes (Cluster Content):** 15-20 related articles linking back to hub

**Example: Swing Trading Hub**
```
/swing-trading-guide (Pillar - 4K words)
├── /swing-trading-entry-signals
├── /swing-trading-stop-loss-placement
```
