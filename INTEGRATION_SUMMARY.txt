ENVIRONMENT VARIABLES (4 NEW)
================================================================================

MEDIUM_API_KEY
   Source: https://medium.com/settings/security
   Format: Bearer token
   Required for Medium publishing

MEDIUM_AUTHOR_ID
   Source: curl -H "Authorization: Bearer TOKEN" https://api.medium.com/v1/me
   Format: UUID string (e.g., c64d1c9f-e473-408d-8653-f79c43a0e065)
   Required for Medium publishing

RESEND_API_KEY
   Source: https://resend.com/api-keys
   Format: re_<key>
   Required for Resend email distribution

RESEND_AUDIENCE_ID
   Source: https://resend.com/audiences
   Format: UUID string
   Optional for queueing, required for immediate send

QUICK SETUP
================================================================================

Step 1: Configure Environment Variables

   # Medium (from https://medium.com/settings/security)
   export MEDIUM_API_KEY="your-token"
   export MEDIUM_AUTHOR_ID="your-author-id"

   # Resend (from https://resend.com/)
   export RESEND_API_KEY="re_your-key"
   export RESEND_AUDIENCE_ID="your-audience-id"

   # Beehiiv (from https://beehiiv.com/settings)
   export BEEHIIV_API_KEY="your-key"
   export BEEHIIV_PUBLICATION_ID="your-publication-id"

Step 2: Verify Configuration

   cd scripts/
   python MEDIUM_RESEND_CODE_SNIPPETS.py
   # Should show ✓ Ready for all configured platforms

Step 3: Test Integration

   python priority_publishers.py
   # Output shows all 7 channels and their publication status

Step 4: Integrate with Content Quality Gate

   from content_quality_gate import ContentQualityGate
   from priority_publishers import publish_to_priority_platforms

   gate = ContentQualityGate()
   validation = gate.validate_article(article)

   if validation.publish_status == "publish":
       results = publish_to_priority_platforms(article, include_email=True)
       print("Published to all platforms")
