## Quick Reference: Formula Cheat Sheet

```markdown
# Revenue Tracking Formulas

## Daily Totals
```
Daily Total = Email + Social + YouTube + Sponsors
```

## Weekly Aggregates
```
Week Total = SUM(Daily Total for Mon–Sun)
Week Avg Daily = Week Total / 7
Best Day = MAX(Daily Total for week)
Lowest Day = MIN(Daily Total for week)
Active Days = COUNT(Daily Total > $0)
```

## Monthly Aggregates
```
Month Total = SUM(Week Total for all weeks)
Month Avg Daily = Month Total / Days in Month
Month Avg Weekly = Month Total / Number of Weeks
% of Goal = (Month Total / Monthly Target) × 100
YTD Total = SUM(Month Total Jan–Current Month)
```

## Channel Mix
```
Email % = (Email Total / Month Total) × 100
Social % = (Social Total / Month Total) × 100
YouTube % = (YouTube Total / Month Total) × 100
Sponsors % = (Sponsors Total / Month Total) × 100
```

## Growth Metrics
```
MoM Growth % = ((This Month - Last Month) / Last Month) × 100
WoW Growth % = ((This Week - Last Week) / Last Week) × 100
YoY Growth % = ((This Year - Last Year) / Last Year) × 100
3-Month Moving Avg = (Month 1 + Month 2 + Month 3) / 3
```

## Performance Indicators
```
Conversion Rate = (Transactions / Clicks or Visits) × 100
AOV (Avg Order Value) = Total Revenue / Total Transactions
Revenue per Day = Month Total / Days Active
Revenue per Channel Effort = Channel Revenue / Hours Invested
```

## Implementation Guide

### Setup Instructions

1. **Create Three Files in Your System**
   - `daily_revenue_log_YYYY-MM-DD.md` — one per day
   - `weekly_revenue_summary_WK#_YYYY.md` — one per week
   - `monthly_revenue_rollup_MMMM_YYYY.md` — one per month

2. **Populate with Real Data Daily**
   - Log all transactions in Daily Log
   - Update channel amounts before 11pm each day
   - Move completed daily logs to archive folder

3. **Generate Weekly Summary Every Monday**
   - Copy Week template
   - Calculate daily averages from daily logs
   - Identify top performers + blockers
   - Plan next week actions

4. **Complete Monthly Rollup on Last Day**
   - Aggregate all 4 weekly summaries
   - Compare vs targets + prior months
   - Document lessons learned
   - Set next month goals

### Integration with CRM/Tools

| Tool | Action | Frequency |
|------|--------|-----------|
| **Mailchimp** | Export daily affiliate conversions | Daily |
| **Google Analytics** | Sync YouTube AdSense + referral revenue | Daily |
| **Stripe** | Pull sponsor payment confirmations | Daily |
| **Instagram / TikTok** | Log affiliate link clicks from bio | Daily |
| **Spreadsheet (optional)** | Mirror markdown tables for charting | Weekly |
| **Slack / Discord** | Post daily summary as message | Daily |
