================================================================================
ARCHITECTURE HIGHLIGHTS
================================================================================

Design Principles:
  * Graceful Degradation: Missing credentials = skip (no error)
  * Structured Logging: All ops via Python logging module
  * Error Resilience: Exception handling per-platform
  * Type Safety: Full type hints for IDE autocomplete
  * Security: Environment variables only, never hardcoded
  * Batch Operation: Publish to all platforms simultaneously

Key Features:
  * OAuth 2.0 for all platforms (no API keys, except credentials)
  * Automatic token refresh (LinkedIn, YouTube)
  * Resumable uploads (YouTube, large files)
  * 2-step publishing (Instagram: create media then publish)
  * Rate limit handling (per-platform recommendations)
  * Comprehensive error messages with context

Function Signatures (Consistent API):
  def publish_PLATFORM(article: Dict, url_or_media: str) -> Optional[str]

  Returns:
    - Published post URL (success)
    - None (skipped or failed)

Batch API:
  def publish_to_all_platforms(article, canonical_url, image_url,
                              video_url, video_path) -> Dict[platform: url]

USAGE EXAMPLES

1. Publish to All Platforms

from scripts.social_media_publishers import publish_to_all_platforms

article = {
    "title": "10 Trading Strategies",
    "meta_description": "Proven strategies",
    "body": "Full content..."
}

results = publish_to_all_platforms(
    article=article,
    canonical_url="https://profitengine.alreadyherellc.com/article",
    image_url="https://cdn.example.com/image.jpg",
    video_url="https://cdn.example.com/video.mp4",
    video_path="/tmp/video.mp4"
)

for platform, url in results.items():
    if url:
        print(f"{platform}: {url}")


2. FastAPI Webhook Integration

@app.post("/api/webhooks/blog")
async def blog_published(request: Request):
    data = await request.json()
    results = publish_to_all_platforms(data["article"], data["url"])
    return {"results": results}


3. Scheduled Publishing

@scheduler.scheduled_job('cron', hour=9, minute=0)
def daily_post():
    article = get_latest_article()
    results = publish_to_all_platforms(article, article.url)

================================================================================
SECURITY & ROTATION
================================================================================

Credential Rotation Schedule:

Quarterly:
  * Twitter: Regenerate Bearer Token or API Key/Secret
  * Reddit: Regenerate Client ID/Secret
  * LinkedIn: Regenerate access token (90-day expiry)
  * Facebook/Instagram: Review permissions (indefinite)
  * TikTok: Regenerate access token
  * YouTube: Review refresh token (indefinite until revoked)

Immediate (Upon):
  * Team member departure
  * Security incident or token leak
  * Account suspension or 401 errors
  * Platform policy changes

Best Practices:
  * Never commit credentials to git
  * Use environment variables only
  * Enable MFA on all accounts
  * Monitor API usage logs weekly
  * Request minimum required scopes
  * Audit connected apps quarterly
