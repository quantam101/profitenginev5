CORE API METHODS
================================================================================

1. CatalystScorer(finnhub_api_key, alpaca_api_key)
   Initialize scorer with API keys (defaults from env vars)

2. score_catalysts(symbol: str) -> float
   Returns 0-100 catalyst score
   Example: score = scorer.score_catalysts('AAPL')

3. get_catalyst_details(symbol: str) -> dict
   Returns detailed catalyst breakdown with metadata
   Example: details = scorer.get_catalyst_details('AAPL')

4. weight_signal_by_catalyst(base_signal: float, catalyst_score: float) -> float
   Adjusts trading signal by catalyst strength
   Example: adjusted = scorer.weight_signal_by_catalyst(0.75, 65.0)

================================================================================
SIGNAL WEIGHTING FORMULA
================================================================================

adjusted_signal = base_signal * (1 + (catalyst_score / 100) * 0.5)

Amplification Examples:
  catalyst_score=0:   multiplier = 1.0   (no change)
  catalyst_score=50:  multiplier = 1.25  (+25% boost)
  catalyst_score=100: multiplier = 1.5   (+50% boost, capped at 1.0)

Signal Adjustment Examples:
  base=0.75, score=0:   adjusted = 0.75   (no change)
  base=0.75, score=50:  adjusted = 0.9375 (+25%)
  base=0.75, score=100: adjusted = 1.0    (+50%, capped)

INTEGRATION PATTERNS
================================================================================

Trading Strategy:
  1. Get base signal from technical analysis
  2. Call scorer.score_catalysts(symbol)
  3. Adjust signal: adjusted = scorer.weight_signal_by_catalyst(base, score)
  4. Use adjusted signal for trade decisions

Risk Management:
  1. Score catalysts for each symbol
  2. Scale position size by catalyst score
  3. Reduce size if score is low, increase if high

FastAPI Endpoints:
  POST /api/v1/catalysts/score/{symbol}
  GET /api/v1/catalysts/details/{symbol}
  POST /api/v1/catalysts/adjust-signal

Logging:
  1. Call scorer.get_catalyst_details(symbol)
  2. Log the returned dict with cycle_log or similar
  3. Track catalyst history for analysis

   echo $FINNHUB_API_KEY

   status.finnhub.io
