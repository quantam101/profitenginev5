### Template Files (POST_TEMPLATES/)

**strategy-deep-dive-template.md** (3,500 words)
- Reusable 8-part structure
- How to explain any trading strategy
- Includes: Hook, history, backtest, failure point, regime filter, validation, execution, CTA
- Time to complete: 2-3 hours
- Result: 6-8 part Threads thread + carousel + LinkedIn article
- **Use for**: Mean reversion, momentum, volatility, sector rotation, etc.

**backtest-results-template.md** (3,000 words)
- Reusable 6-part structure
- How to showcase backtest performance
- Includes: Results, stress test, trade-offs, live performance, next tests
- Time to complete: 1-2 hours
- Result: 4-6 part Threads thread + carousel + LinkedIn post
- **Use for**: Weekly/monthly backtest showcases

**risk-management-template.md** (3,500 words)
- Reusable 6-part structure
- How to create safety/risk-focused content
- Includes: Hook, math, rules, failure cases, adjustments, CTA
- Time to complete: 1.5-2 hours
- Result: 5-6 part Threads thread + carousel + LinkedIn article
- **Use for**: Position sizing, drawdowns, stops, psychology

**market-analysis-template.md** (2,500 words)
- Reusable 4-part structure
- How to do daily/weekly market commentary
- Includes: Hook, data/chart, implication, contrarian angle
- Time to complete: 30-60 minutes
- Result: 3-4 part Threads thread + Instagram stories + reel
- **Use for**: Daily market takes, technical analysis, macro

## How This Was Designed

Each file builds on the others:

```
CONTENT_FRAMEWORK_README.md
├── "What is this?" (overview)
├── "How long does it take?" (time breakdown)
├── "What should I track?" (metrics)
└── "Go read the other files" (navigation)

CONTENT_CALENDAR_MONTHLY.md
├── "Here are 17 specific posts" (ready to publish)
├── "Each has a hook, outline, CTA" (structure)
├── "Each has engagement targets" (what to expect)
└── "Use the templates to write them" (link to next file)

SOCIAL_DISTRIBUTION_GUIDE.md
├── "Post on Threads using this schedule" (timing)
├── "Post on Instagram using these formats" (carousel/reel)
├── "Post on LinkedIn using this angle" (B2B)
└── "Amplify on Discord/community" (next file)

COMMUNITY_ENGAGEMENT_PLAYBOOK.md
├── "Find traders to engage with" (sourcing)
├── "Reply genuinely" (tactics)
├── "Build relationships" (long-term)
└── "Moderate community" (infrastructure)

POST_TEMPLATES/
├── "Write strategies this way" (deep-dive template)
├── "Showcase backtests this way" (results template)
├── "Write about risk this way" (safety template)
└── "Do market analysis this way" (analysis template)
```

Each file is complete on its own AND references the others for depth.
