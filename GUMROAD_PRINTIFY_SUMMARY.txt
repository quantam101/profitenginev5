NEW FUNCTIONS ADDED
===================

_word_count(text) -> int
  Count words in markdown text, excluding formatting

_get_product_suggestions(article) -> List[str]
  Smart POD product suggestions based on article topic
  Returns: ["t-shirt", "mug", "hoodie"] etc.

_convert_article_to_ebook(article) -> Optional[str]
  Generate markdown ebook with front matter
  Returns: Path to generated ebook file

_publish_to_gumroad(ebook_path, article) -> Optional[Dict]
  Upload ebook to Gumroad via API
  Returns: Product ID, URL, price, status

_create_printify_product(article, product_type) -> Optional[Dict]
  Queue POD product creation on Printify
  Returns: Product ID, dashboard link, status

_build_monetization_report(...) -> Dict[str, Any]
  Generate comprehensive monetization report
  Returns: Full report with revenue estimates

CONFIGURATION
==============

Environment Variables (All Optional):

GUMROAD_ENABLED=true
  Enable/disable ebook publishing (default: true)

GUMROAD_API_KEY=prod_xxx...
  Required for publishing (get from Gumroad account)

GUMROAD_BASE_PRICE=4.99
  Ebook price in USD (default: 4.99)

GUMROAD_AMAZON_TAG=alreadyhere-20
  Amazon Associates tag in ebook footer

PRINTIFY_ENABLED=true
  Enable/disable POD product creation (default: true)

PRINTIFY_API_KEY=sk_live_xxx...
  Required for product creation (get from Printify account)

EBOOK_WORD_LIMIT=1000
  Minimum words to trigger ebook (default: 1000)

GitHub Secrets (for CI/CD):
  GUMROAD_API_KEY
  PRINTIFY_API_KEY
