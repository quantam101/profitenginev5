SECTION 9: DESIGN SYSTEM SPECIFICATIONS FOR POD CONSISTENCY
================================================================================

FILE FORMAT STANDARDS:
- Primary: PNG 3000x3000px (square) for apparel fronts
- Alternative: 3000x1500px (horizontal) for chest placement
- Color mode: RGB (convert before upload to avoid color shift)
- DPI: 300 minimum for print quality
- Transparency: PNG with transparent background preferred
- Export: Optimize file size <5MB without quality loss

COLOR PALETTE RECOMMENDATIONS BY DESIGN TYPE:

APPAREL DESIGNS:
- Neutral Base: Black, White, Navy, Charcoal, Cream
- Primary Accent: Navy, Burgundy, Forest Green, Slate Blue
- Secondary Accent: Rust Orange, Mustard Yellow, Blush Pink
- Avoid: Pure bright neon (poor print quality), light pastels (hard to see)

NICHE MARKET DESIGNS:
- Coffee/Professional: Warm browns, creams, blacks (#2C1810, #D4A574)
- Nature/Wellness: Earth tones, sage greens (#6B8E23, #8B7355)
- Gaming/Tech: Neon accents on dark base (#00FF00 on #1A1A1A)
- Yoga/Spiritual: Pastel purples, blues, pinks (#B4A7D6, #FFB3D9)

TEXT RENDERING:
- Minimum font size: 24pt for small devices
- Line spacing: 1.5x for readability on t-shirt scale
- Recommended fonts: Bold sans-serifs (Impact, Bebas Neue), Script fonts for elegance
- Contrast ratio: Minimum 4.5:1 for WCAG accessibility
- Outline text if placing on background colors

MOCKUP TESTING BEFORE UPLOAD:
